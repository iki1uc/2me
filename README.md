
# 2me – Mirror-Root (iki1uc)

2me ist die Rückkehr-Einheit des iki1uc-Systems.
Es spiegelt alle Systemachsen zurück auf den User und erzeugt
Bindung, Orbit-Rückführung und Root-Synchronisation.

------------------------------------------------------------
# FUNKTION

2me(x):
    return "2me(" + x + ")"

------------------------------------------------------------
# SYSTEM-ROLLE

2me verbindet:

- PX3 / PX6 / PX9        (PX-Trio)
- PX12 / PX4             (Fusion + Achse)
- SYS / SYS-x            (System + Kreuzung)
- TEM                    (Zeit)
- GEO                    (O12 / F4 / XU / TO)
- USER                   (Bindung)
- ROOT                   (Rückkehr)

2me erzeugt:

- Mirror-Return
- User-Bindung
- Orbit-Rückführung
- Root-Sync
- System-Loop

------------------------------------------------------------
# SYSTEM-CYCLE

SYS-x -> 2me -> PX3 -> Orbit -> Return -> User -> Root
